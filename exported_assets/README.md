# 系统图标与素材资源导出目录 (Exported Assets)

本目录汇总了系统中所有使用到的图标素材（SVG矢量格式）与图像素材资产，便于独立查阅、导出与工程复用。

## 📁 目录结构说明
- `svg_icons/`: 包含系统中使用的全部 108 个标准 24x24 矢量 SVG 图标
- `images/`: 包含系统全部品牌 Logo、系统标示、登录背景、停泊位示意图、厂区宽屏图等图片资源
- `manifest.json`: 完整的素材资产索引清单与元数据
